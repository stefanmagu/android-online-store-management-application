# Proiect
## Aplicație de Gestiune a unui magazin online
O aplicație în care utilizatorii își creează un coș de cumpărături virtual și îl pot gestiona.

## Funcționalități:
### Activități pentru: adăugare produse, vizualizare coș, detalii despre produse, statistici cheltuieli
### Formular pentru introducerea produselor (nume, preț, cantitate).
### Transfer de parametri: detalii despre produs între activități.
### SQLite cu două tabele: Produse și Categorie.
### Filtrare produse după categorie și afișare în RecyclerView.
### Grafic bidimensional pentru reprezentarea cheltuielilor per categorie.
